# Lullable — Site Spec

The page is built. This file records the decisions behind it so the next change doesn't undo them.
Everything lives in [index.html](index.html): one file, no build step, no framework, no web fonts. It loads in under 50KB and deploys as a static file. When there's a signup flow, a paywall, and a library, it becomes a Next.js app — not before.

---

## 1. Information architecture & dark-mode UX principles

### Site map (today)

```
/                     one page: hero → manifesto → matrix → last-fact → signup
/og.png               link preview — generated by make-card.py
/audio/*.mp3          samples, served static
<unlisted>            Midnight Salon pages — unguessable URLs, announced only in the newsletter footer
```

Everything else — pricing, library, account — waits until 500 subscribers prove the worldview lands.

### The one governing rule

**Nothing on this page should be bright enough to wake someone up.** It is browsed in bed, in the dark, one-handed, often after a failed attempt at sleep. Every token below follows from that.

### Palette — "Nightfall" (imported from the Claude Design project)

Source of truth: `design/tokens/colors.json` in the claude.ai/design project (id `97dc862a…`). Dark is the canonical appearance. The system's one hard rule, kept everywhere:

> **Amber marks the playback and conversion path only; Iris marks navigation and atmosphere. They never share a job.**

| Token | Value | Role (from the token file) |
|---|---|---|
| `--ink` | `#0E0F16` | Ground — the page. |
| `--ink-2` | `#171823` | Surface: player card, fields. |
| `--ink-3` | `#1F2130` | Raised: inputs, sheets. |
| `--haze` | `#262937` | Line: dividers, hairline borders. |
| `--text` | `#EDE7DE` | Text primary — warm ivory, never `#FFF`. |
| `--dim` | `#9B97A8` | Text secondary: body copy, blurbs. |
| `--dimmer` | `#6C6879` | Text tertiary — small labels only, **never body copy**. |
| `--amber` | `#DFAF83` | Play button, progress fill, app CTAs, the "us" matrix column. |
| `--iris` / `--iris-dim` | `#A79FD9` / `#9C93CE` | Overlines/eyebrows, the top-of-page dusk glow, focus rings, selection, list markers. |
| `--err` | `#C97B7B` | Form/playback failure only. |

Component idioms adopted from the prototype: 16–18px card radii, `linear-gradient(160deg, …)` duotone covers on the morning card and testimonials, `0 12px 30px rgba(0,0,0,.5)` shadows, 500-weight `.14em` uppercase overlines.

### Evening-browsing layout rules

- Single column, centered, generous vertical rhythm (5.5rem between sections) — a slow scroll, not a dashboard.
- Reading measure capped at `34rem`. The manifesto is the product's voice; it must never run wide.
- **Serif: Newsreader** (the Nightfall system serif — the one web font we load, `display=swap` with Georgia fallback so text renders instantly and nothing shifts). **System sans** for UI.
- Motion: nothing faster than 400ms, no entrance animations, no parallax. One fixed radial glow at the top of the page — a lamp, not an effect. `prefers-reduced-motion` kills the rest.
- Accessibility: amber focus rings, `aria-live` form status, real `<th scope>` in the table, touch targets ≥ 44px.

## 2. Hero section

### Headline (shipped)

> **Bedtime stories for adults who *can't stop thinking*.**

Identity-driven, zero hype: it names the reader, not the product. Runners-up kept for testing: *Your brain isn't broken. It's just curious.* / *Knowledge that doesn't demand anything back.* / *Fascinating truths, told softly.*

Kicker names the category (*the low-arousal knowledge engine*); the subhead is the brand anthem, nearly verbatim — "people like us" doing the work of a paragraph of positioning.

### CTAs

- **Primary — App Store waitlist badge.** Styled like a store badge (Apple glyph, two-line label: "Coming to the App Store / Join the waitlist") but pointing at the signup module — because the waitlist *is* the permission list. No fake store link, ever.
- **Secondary — "Boringly Brilliant" opt-in**, a quiet ghost link to the same module.
- **The real primary is the play button.** The sampler is the pitch; two minutes of it explains more than any copy. Under it: *"No account. No card."*

### Interactive audio sampler widget

| | |
|---|---|
| Length | 120s, cut from the real 45-minute episode |
| Source | `audio/sample-mariana-trench.mp3`, mono, 64kbps — voice only, small file |
| Preload | `none`. Nothing downloads until pressed. |
| Controls | Play/pause and a thin progress line. No scrubbing, no volume, no speed — scrubbing implies there's a good bit. |
| **Built-in fade** | **The last 30 seconds ramp to silence** (squared curve, in JS — `FADE_SECONDS`). Every recording ends the way we hope the listener will. The fade is the widget's thesis stated in audio. |
| Captions | Timed serif lines fade in beneath the player (array in the script). Sound-off visitors still get the sensation. |
| Failure | If the file 404s, the player says *"Sample not uploaded yet"* and points at the newsletter. It never fakes success. |
| Events | `sample_play`, `sample_finished`, `sample_missing` |

**The number that matters: % of visitors who press play.** Below 15%, the headline is wrong — not the audio.

### Narration direction (for whoever records it)

Warm, unhurried, academic. Remove emphasis rather than add it; sentences end downward; give the ending away in the first line. If a take sounds exciting, it's wrong — do it again more gently.

## 3. "A Manifesto for Overthinkers"

~300 words on the page, set in serif at 1.13rem/1.75, 34rem measure, two amber pull-quote breaks maximum.

The argument, in order: **absolution** (your brain isn't broken — the "breathe into your belly" moment named) → **diagnosis** (an unoccupied mind goes looking for work; the Tuesday simulations) → **recognition** (white noise's loop, podcasts at 1.5×) → **the reframe**, as the pull quote (*you don't need to force your brain shut; give it something peaceful to ponder*) → **the mechanism** (endings first, volume drifts down) → **the luxury** (Zero Retention Required — no quiz, ever) → a six-word invitation (*come think about something else*).

It speaks to the reader's frustration with traditional sleep apps without naming a brand. Contempt for the incumbents' premise, warmth for the reader — never the reverse.

## 4. Comparison strip

Four cards, one line each, in Goldilocks order — the whole positioning argument in under forty words:

- **Podcasts** — too interesting; you stay up for the ending.
- **White noise** — too empty; your mind wanders back to work.
- **Meditation** — too demanding; "empty your mind" is homework.
- **Lullable** — just enough; it occupies your mind until it lets go.

Design choices: line-icon per card (dimmer stroke; Lullable's play glyph in amber — the playback path); the Lullable card carries the amber wash and border so it reads as the answer, not a fourth problem; grid stacks 2-up then 1-up on mobile — no sideways scrolling anywhere on the page. (An earlier five-vector argued table lives in git history if a deeper comparison page is ever wanted for SEO.)

## 5. Permission capture module + link preview

### "Join the Midnight Salon"

The module sells three things as one signature: the Sunday letter, first access to 11:11pm Salon drops, and the App Store waitlist. One field, one button (**"Join the Midnight Salon"** — an invitation to a place, not a subscription to content).

Mechanics: plain `<form>` + `fetch`, ~30 lines, no vendor script, no cookies (so no banner). **Two swaps before launch,** both marked TODO at the top of the script:

1. `SUBSCRIBE_URL` — anything accepting a POST with an `email` field. Buttondown's embed endpoint (`https://buttondown.com/api/emails/embed-subscribe/YOUR-USERNAME`) needs no key and no backend; free to 100 subscribers, then $9/mo. If it goes down, signups fail loudly — acceptable now.
2. `EVENTS_URL` — optional; events log to console until set.

Until wired, the form says so plainly rather than pretending to succeed.

**The four promises, printed beside the field, not buried in a policy:** one letter a week, never two · never a notification after 9pm, ever · one-click unsubscribe, no questions · never sell, rent, or "partner" the address. Permission-marketing terms of trade; the 9pm line is a product promise disguised as a privacy promise.

### Link preview

`og.png` is **not a logo** — it's the morning card itself (MARKETING.md §4): *"Last night, you drifted off while learning about…"*, the severed quote, the exact timestamp. A stranger seeing the link in a group chat understands the entire company before clicking. Generated by [make-card.py](make-card.py), which is also the production renderer for every user's morning card once the app exists. One script, two uses, no design tool in the loop.

### Events

`page_view`, `sample_play`, `sample_finished`, `sample_missing`, `signup`, `signup_failed`, `signup_unwired`. Email domain only in metadata — never the address.

The funnel: `page_view → sample_play → signup`. Week-one targets: 15% play, 6% signup.
